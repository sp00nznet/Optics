# Contributing

Issues and pull requests are welcome.

- Build and run the checks before sending a PR:
  `cmake --build build --config Release`, `build\bin\optics-check.exe --selftest`,
  `build\bin\optics-check.exe --check sample-models tests\expected.tsv`.
- Keep it C11, no new dependency without a reason. A new third-party file gets a `NOTICE`
  row and its licence under `LICENSES/` in the same PR.
- A change to what loads, or to the counts, updates `tests/expected.tsv` (`--update`) and
  says why in the PR.
- Model files you add to `sample-models/` must be CC0 or generated by a script in `tools/`,
  with a row in `PROVENANCE.md`.

## Where your code comes from

Contributions must be your own or under an MIT-compatible licence. Do not port code from
GPL, LGPL or other copyleft projects (Assimp is BSD and fine; OpenCascade is LGPL and is
not; Blender's source is GPL), even rewritten. If you followed one, say so in the PR.

AI-assisted contributions are welcome, provided a human understood and verified the change.
